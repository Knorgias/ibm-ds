# ibm-ds

Figma → code demo: a screen designed in Figma against the real IBM
Carbon v11 component library, pulled via Figma MCP, and hand-coded with
`@carbon/web-components`. See [demo.md](demo.md) for the full pitch and
[HANDOVER.md](HANDOVER.md) for project background.

## Run locally

Requires Node.js.

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
```

Outputs to `dist/`.
